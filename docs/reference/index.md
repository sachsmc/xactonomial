# Package index

## Main function

Primary user-facing function

- [`xactonomial()`](https://sachsmc.github.io/xactonomial/reference/xactonomial.md)
  : Improved inference for a real-valued function of multinomial
  parameters

## Helper functions

Everything else

- [`calc_multinom_probs()`](https://sachsmc.github.io/xactonomial/reference/calc_multinom_probs.md)
  : Calculate multinomial probabilities
- [`calc_prob_null()`](https://sachsmc.github.io/xactonomial/reference/calc_prob_null.md)
  : Calculate probability for given parameters
- [`calc_prob_null_fast()`](https://sachsmc.github.io/xactonomial/reference/calc_prob_null_fast.md)
  : Calculate probability for given parameters
- [`calc_prob_null_gradient()`](https://sachsmc.github.io/xactonomial/reference/calc_prob_null_gradient.md)
  : Gradient of the multinomial likelihood sum
- [`combinate()`](https://sachsmc.github.io/xactonomial/reference/combinate.md)
  : Arrange all combinations of rows of two matrices
- [`combinate2()`](https://sachsmc.github.io/xactonomial/reference/combinate2.md)
  : Like combinate but adds on to previous call
- [`itp_root()`](https://sachsmc.github.io/xactonomial/reference/itp_root.md)
  : Find a univariate root of the function f
- [`log_multinom_coef()`](https://sachsmc.github.io/xactonomial/reference/log_multinom_coef.md)
  : Calculate log of multinomial coefficient
- [`pvalue_psi0()`](https://sachsmc.github.io/xactonomial/reference/pvalue_psi0.md)
  : Compute a p value for the test of psi \<= psi0 and/or psi \>= psi0
- [`rdirich_dk_vects()`](https://sachsmc.github.io/xactonomial/reference/rdirich_dk_vects.md)
  : Sample independently from Dirichlet distributions for each of d_k
  vectors
- [`runif_dk_vects()`](https://sachsmc.github.io/xactonomial/reference/runif_dk_vects.md)
  : Sample uniformly and independently from d_k simplices
- [`sample_unit_simplexn()`](https://sachsmc.github.io/xactonomial/reference/sample_unit_simplexn.md)
  : Sample n times from the unit simplex in d dimensions
- [`sspace_multinom()`](https://sachsmc.github.io/xactonomial/reference/sspace_multinom.md)
  : Enumerate the multinomial sample space
- [`sspace_multinom_sample()`](https://sachsmc.github.io/xactonomial/reference/sspace_multinom_sample.md)
  : Get a sumsample of the multinomial sample space
- [`sspace_multinom_slow()`](https://sachsmc.github.io/xactonomial/reference/sspace_multinom_slow.md)
  : Enumerate the sample space of a multinomial
